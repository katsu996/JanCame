# 牌認識 実機検証チェックリスト

JanCame の牌認識を実機で受け入れ確認する手順です。  
`improve-tile-recognition` で未実施だった **7.1（認識率）** と **7.2（性能・応答性）** に対応します。

## 推奨環境

| 項目 | 推奨 |
|------|------|
| 端末 | 中級スマホ相当（例: Pixel 6a、iPhone SE 3、同等 Android） |
| ブラウザ | Chrome / Safari 最新 |
| URL | 本番 `https://katsu996.github.io/JanCame/?debug=1` または `pnpm preview:pages` + `?debug=1` |
| 手牌 | 実牌 14 枚、正面・均一照明・背景コントラストあり |
| ROI | 手牌全体が黄色枠内に収まるよう調整 |

## デバッグ表示

URL に `?debug=1` を付けると、ヘッダー下に以下が表示されます。

- **処理時間** — 直近フレームの認識パイプライン所要時間（ms）
- **認識枚数** — 閾値以上で認識された枚数 / スロット数
- **パイプライン** — Worker / メインスレッド

## 7.1 認識率（10/14 以上）

### A. カメラモード

- [ ] アプリを開き、カメラ権限を許可
- [ ] 実牌 14 枚をカメラに向ける
- [ ] ROI を手牌に合わせる
- [ ] 認識 ON、10 秒程度観察
- [ ] 正しく認識された枚数: ___ / 14
- [ ] **合格**: 10 枚以上

**記録**

| 日付 | 端末 | ブラウザ | 認識数 | 合格 |
|------|------|----------|--------|------|
|      |      |          |        |      |

### B. 画像モード

- [ ] 同じ手牌を撮影した JPEG/PNG をアップロード
- [ ] ROI を調整
- [ ] 認識結果を確認
- [ ] 正しく認識された枚数: ___ / 14
- [ ] **合格**: 10 枚以上

**記録**

| 日付 | 端末 | ファイル名 | 認識数 | 合格 |
|------|------|------------|--------|------|
|      |      |            |        |      |

### 未達時の対処

1. `public/assets/tiles/` に自分の牌セットの 48×64 PNG を配置（`public/assets/tiles/README.md` 参照）
2. 照明・ROI 位置を再調整
3. 開発者向け: `src/recognition/match.ts` の `MATCH_THRESHOLD`（初期 0.72）を 0.65〜0.75 で調整
4. 再検証し記録表を更新
