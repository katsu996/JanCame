# Proposal: JanCame MVP

## Why

麻雀プレイヤーが隙間時間に手牌の牌効率（向聴数・最適打牌）を確認したいが、既存ツールは手動入力が必要で手間がかかる。物理的な手牌をカメラに向けるだけで向聴と打牌候補を得られる Web アプリがあれば、練習・復習のハードルが大幅に下がる。

重いディープラーニング（YOLO 等）はブラウザでの初回ロード・バッテリー消費が大きいため、OpenCV.js によるテンプレートマッチングと静的ホスティング可能なサーバーレス構成を採用する。

## What Changes

JanCame MVP として、以下を新規構築する。

1. **Web カメラキャプチャ** — ライブ映像から数 FPS でフレームを取得
2. **画像認識モジュール** — OpenCV.js で手牌領域の切り出し・34種牌の識別
3. **牌効率計算モジュール** — 向聴数と打牌ごとの受け入れ枚数を算出
4. **UI オーバーレイ** — 映像上に牌ラベル・「切」マーク、パネルに打牌候補リスト

## Capabilities

### New Capabilities

- `camera-capture`: Web カメラ取得・フレーム間引き・権限エラー処理
- `tile-recognition`: OpenCV.js による前処理・パース補正・34種テンプレートマッチング
- `tile-efficiency`: 向聴数・打牌候補・受け入れ牌・受け入れ枚数の計算
- `ui-overlay`: カメラ映像オーバーレイ・打牌推奨パネル・手動補正 UI

### Modified Capabilities

（既存 spec なし — 新規プロジェクト）

## Impact

- **新規コードベース**: Vite + TypeScript SPA、OpenCV.js、牌効率 TS モジュール
- **静的アセット**: 34種牌テンプレート画像（`/assets/tiles/`）
- **デプロイ**: GitHub Pages / Cloudflare Pages / Vercel 等の静的ホスティング
- **プライバシー**: 映像は端末内処理のみ、サーバー送信なし
- **非ゴール（MVP）**: 他家の河・ドラ・役計算・鳴き牌効率・ネイティブアプリ・ユーザー認証
